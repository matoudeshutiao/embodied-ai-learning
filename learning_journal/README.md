# 学习原始记录

这个目录放用户自己的原始记录，不是 Claude 的总结。

## 每天创建

```text
learning_journal/YYYY-MM-DD-dayN/
├── raw.md
├── reflection.md
└── assets/
```

## raw.md 模板

```markdown
# 原始记录

## 今天的目标/预测

我以为会发生什么：

## 执行的命令

```bash
# 命令
```

## 实际输出/报错

```text
# 原始输出
```

## 我的困惑

- 

## 失败尝试

- 

## 截图

- assets/xxx.png
```

## reflection.md 模板

```markdown
# 我的反思

## 三句话

1. 我以为会发生什么：
2. 实际发生了什么：
3. 下次我要怎么验证：

## 我现在的解释

用自己的话解释，不看 Claude 的总结。

## 还没想明白的问题

- 
```

## 规则

- 原始输出不要先“润色”；
- 失败和报错优先保留；
- 截图放在同一天的 `assets/`；
- Claude 整理后的内容要链接回这里；
- 没有 `raw.md` 和 `reflection.md` 的一天，不算完整学习记录。
