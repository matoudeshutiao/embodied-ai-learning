# Day 31 学习笔记：从像素到抓取

## 1. 为什么需要反投影

相机给的是一张 2D 像素图，机械臂要的是 3D 坐标。

```text
像素 (u, v)          只知道“在画面哪里”
机械臂目标 (x, y, z)  米制坐标，在 panda_link0 下
```

一个像素只说明方向，不说明距离。反投影把“方向 + 深度”变成 3D：

```text
像素 (u, v) + 深度 Z + 内参 K
        ↓ 反投影
相机坐标 (X, Y, Z)
        ↓ 外参 / TF
panda_link0 下的 (x, y, z)
```

没有反投影，MoveIt 只拿到一个像素编号，没法规划。

## 2. 参数分别是什么

pinhole 相机模型：

```text
u = fx * X / Z + cx
v = fy * Y / Z + cy
```

反过来（反投影）：

```text
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
```

| 参数 | 含义 | 单位 | 直觉 |
|---|---|---|---|
| `u` | 像素列坐标，向右为正 | 像素 | 目标在画面左右哪里 |
| `v` | 像素行坐标，向下为正 | 像素 | 目标在画面上下哪里 |
| `X, Y, Z` | 相机坐标系下的 3D 点 | 米 | `Z` 是深度，`X/Y` 是横向偏移 |
| `fx` | 水平焦距（以像素计） | 像素 | 越大越“放大”，视野越窄 |
| `fy` | 垂直焦距 | 像素 | 通常和 `fx` 接近 |
| `cx` | 主点列坐标 | 像素 | 光轴打在图像上的位置 |
| `cy` | 主点行坐标 | 像素 | 通常接近图像中心 |

`fx, fy, cx, cy` 就是**内参**。真实镜头还会有畸变参数
`k1, k2, p1, p2, k3`；Gazebo 仿真默认没有畸变。

例子（当前 320×240 相机）：

```text
fx ≈ 277, fy ≈ 277, cx = 160, cy = 120
一个 3D 点 X=0.05 m, Z=0.75 m
u ≈ 277 × 0.05 / 0.75 + 160 ≈ 178.5 像素
在这个深度下，1 像素 ≈ 0.75 / 277 ≈ 2.7 mm
```

## 3. 内参和外参

```text
3D 世界点 P
   │  外参：相机装在哪、朝哪看（旋转 R + 平移 t）
   ▼
相机坐标 (X, Y, Z)
   │  内参：fx, fy, cx, cy（+ 畸变）
   ▼
像素 (u, v)
```

| | 内参 | 外参 |
|---|---|---|
| 回答什么 | 这台相机怎么把 3D 投影成 2D | 相机相对机器人/末端在哪里 |
| 包含 | `fx, fy, cx, cy`、畸变 | 旋转 + 平移（6 自由度） |
| 类比 | 相机的“度数和画面中心” | 相机“站在哪、朝哪看” |
| 误差表现 | 径向缩放、画面中心偏移 | 整体平移、旋转/倾斜 |
| 怎么标定 | 棋盘格/ArUco + `cv2.calibrateCamera` | 固定相机标 `camera→base`；腕部相机做 hand-eye（AX=XB） |

腕部相机（eye-in-hand）运行时：

```text
T_base_camera = T_base_flange(q) × T_flange_camera
```

`T_flange_camera` 是手眼标定结果，`q` 是当前关节角。

## 4. 两种误差怎么区分

| 现象 | 更像哪类误差 |
|---|---|
| 检测点向图像中心按比例收缩/扩张 | 内参 `fx/fy` 比例 |
| 所有点整体平移 | 外参平移或 `cx/cy` 偏置 |
| 点整体旋转/倾斜 | 外参旋转 |
| 深度 `Z` 整体偏大/偏小 | 深度尺度或内参 |

我们的数据：

```text
bbox 中心        6.45 mm
顶面 3D 质心      4.08 mm
乘径向缩放 1.024  0.97 mm
```

乘一个缩放就降到约 1 mm，说明主导误差是**内参比例**，不是外参。
静态 TF 在仿真里是精确的，所以外参基本没有误差。

## 5. 怎么减小误差

```text
内参误差：
  棋盘格多角度拍摄 → 标定 fx/fy/cx/cy + 畸变
  → 用标定后的 K 替代 camera_info
  → 看重投影误差

外参误差（固定相机）：
  标定一次 camera → panda_link0

外参误差（腕部相机）：
  hand-eye 标定 camera → 末端法兰
  运行时用正运动学 T_base_flange(q) 组合
```

顺序：**先内参，再外参/手眼**。
内参不准时做手眼，标定结果会把内参误差部分吸收进去，后面很难查。

## 6. 一句话总结

```text
反投影：像素 + 深度 → 3D 坐标，机械臂才抓得到
内参：3D → 像素的比例，错了表现为径向缩放
外参：相机在机器人哪里，错了表现为整体偏移/旋转
我们剩下的 4 mm：内参比例，下一步做相机内参标定
```
